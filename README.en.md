# AI-Powered Predictive Customer Retention Strategy (Churn Prediction)

**Final Project – GCI World 2026 Spring**  
**Matsuo-Iwasawa Laboratory – The University of Tokyo (UTokyo)**

## Project Overview

Developed an end-to-end Machine Learning solution to predict customer churn in a telecommunications company.

The objective was to build a predictive model capable of identifying customers with a high probability of leaving and transforming those predictions into data-driven customer retention strategies.

## Business Problem

The company had access to a large historical customer database but lacked a predictive framework to efficiently identify customers at the highest risk of churn.

The challenge was to convert customer behavior, service usage, and billing data into an analytical decision-support tool capable of improving retention campaigns.

## Technical Approach

- Performed Exploratory Data Analysis (EDA) on approximately 100,000 customer records with multiple behavioral variables.
- Identified customer behavior patterns, missing values, distributions, and key predictive features.
- Engineered business-driven features related to:
  - Customer usage behavior.
  - Customer stability.
  - Billing pressure.
  - Service usage trends.
- Developed and compared multiple Machine Learning models:
  - **LightGBM** to capture complex non-linear relationships.
  - **Logistic Regression with Lasso regularization** for model interpretability.
  - **CatBoost** as a benchmark model.
- Applied **Stratified K-Fold Cross Validation**.
- Optimized the classification threshold to balance Precision and Recall according to business objectives.
- Implemented Explainable AI (XAI) techniques using **SHAP values** to identify the main churn drivers.

## Key Results

- ROC-AUC: **0.704**
- KS Statistic: **0.291**
- Precision@Top10%: **81.25%**
- Recall: approximately **77%**
- Identified the key factors associated with customer churn through model interpretability.

The final solution provides a predictive framework that helps prioritize retention efforts toward customers with the highest probability of churning.

## Technology Stack

Python · Pandas · NumPy · Scikit-Learn · LightGBM · CatBoost · SHAP · Matplotlib · Seaborn · Machine Learning Classification Models

# Sports Analytics & Predictive Modeling: NFL Draft Classification

**GCI Competition – Machine Learning Project**

💻 **Notebook:**

## Project Overview

Developed an end-to-end Machine Learning classification pipeline to predict the probability of college athletes being selected in the NFL Draft.

The project applied classification techniques, feature engineering, and model validation to identify performance patterns associated with draft selection.

## Methodology

- Performed exploratory analysis of athletic performance data.
- Identified predictive patterns in physical and performance-related variables.
- Engineered domain-specific features, including:
  - Speed-to-weight ratio.
  - Explosiveness index.
  - Strength index.
  - Body Mass Index (BMI).
- Processed and analyzed missing values.
- Built classification models using:
  - **Random Forest**.
- Evaluated model performance using:
  - ROC-AUC.
  - Stratified K-Fold Cross Validation.
- Applied techniques to reduce overfitting and improve model generalization.

## Technology Stack

Python · Pandas · Scikit-Learn · Random Forest · Feature Engineering · ROC-AUC
